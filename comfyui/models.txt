# Modelli per ComfyUI: una riga per file.
#
#   <categoria>   <sorgente>   [nome_file]
#
# categoria = cartella sotto ComfyUI/models, anche con sottocartelle (es. loras/flux).
#   Cartelle standard di ComfyUI:
#     checkpoints        modelli completi (SD1.5, SDXL, ...)
#     diffusion_models   solo il modello di diffusione (Flux, Wan, HunyuanVideo, ...)  [ex "unet"]
#     unet               nome vecchio di diffusion_models, ancora letto
#     text_encoders      T5, CLIP-L, umt5, ...  [ex "clip"]
#     clip               nome vecchio di text_encoders, ancora letto
#     clip_vision        encoder di immagini (IP-Adapter, Wan i2v, ...)
#     vae                VAE
#     vae_approx         VAE leggeri per le anteprime (TAESD)
#     loras              LoRA e LyCORIS
#     controlnet         ControlNet e T2I-Adapter
#     upscale_models     ESRGAN, 4x-UltraSharp, ...
#     latent_upscale_models
#     embeddings         textual inversion
#     hypernetworks
#     style_models
#     gligen
#     photomaker
#     model_patches
#     audio_encoders
#     diffusers          modelli in formato diffusers (cartella)
#     configs            file .yaml di configurazione
#   Una categoria diversa viene creata comunque (es. ipadapter, ultralytics/bbox, sams
#   che usano alcuni custom node). Sull'istanza: scripts/add-model.sh --list
#
# sorgente:
#   s3://bucket/percorso/file.safetensors   file dal tuo bucket (credenziali nel template vast)
#   s3://bucket/cartella/                   tutta la cartella (finisce con /)
#   https://...                             link firmato del bucket o qualsiasi URL pubblico
#   https://huggingface.co/...              usa HF_TOKEN se impostato (anche i link "blob")
#   https://civitai.com/api/download/models/<id>   usa CIVITAI_TOKEN se impostato
#
# nome_file: facoltativo. Mettilo quando l'URL non finisce col nome del file
#   (es. CivitAI, link firmati con ?X-Amz-...), così sai come si chiamerà.
